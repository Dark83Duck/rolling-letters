# 우리들의 마음 우체국 (Rolling Letters) 💌

> **선생님께 학생들과 동료 교사들이 따뜻한 마음을 전하는 감성 디지털 롤링페이퍼 웹 애플리케이션**  
> Google Sheets(스프레드시트)를 데이터베이스로 사용하고 Google Apps Script(GAS)로 배포되어, 별도의 서버 비용이나 복잡한 클라우드 설정 없이 **구글 계정만으로 100% 무료로 배포하고 운영**할 수 있습니다.

---

## ✨ 핵심 기능

- 🧺 **살랑거리는 가로 빨랫줄 & 나무 집게**: 편지마다 자연스럽게 바람에 흔들리는 물리 애니메이션
- 🍀 **랜덤 감성 미니 스티커 & ✨ 반짝이 스파클**: 편지마다 행운의 네잎클로버, 벚꽃, 튤립, 작은 별 등 귀여운 스티커와 은은한 황금빛 반짝이 효과
- 📱 **완벽한 반응형 디바이스 최적화**:
  - **스마트폰**: 2열 균형 그리드, 모바일 바텀시트(Bottom Sheet) 모달, iOS 사파리 줌인 방지
  - **태블릿**: 3열 넉넉한 터치 최적화 레이아웃
  - **데스크탑**: 4~5열 파노라마 다단 그리드 및 3D 호버 인터랙션
- 🔒 **4자리 비밀번호 보호 & 수정/삭제**: 편지 작성 시 설정한 4자리 비밀번호로 본인 편지만 안전하게 수정 및 삭제
- 👑 **선생님/관리자 마스터 PIN 삭제**: 학생의 비밀번호를 몰라도 관리자 마스터 PIN(`0000`)으로 부적절한 편지 즉시 정리
- 💖 **실시간 공감(❤️) & 🎉 축하 폭죽(Confetti)**: 하트 클릭 시 위로 떠오르는 하트 파티클 및 편지 읽기 시 축하 꽃가루 효과
- 💻 **로컬 개발 모드 (LocalStorage Fallback)**: Apps Script에 올리기 전 로컬 브라우저에서도 즉시 테스트 가능

## 🚀 3분 완성! Google Apps Script 배포 방법

구글 계정(개인 Gmail 또는 학교 Google Workspace 계정)만 있으면 누구나 3분 만에 무료로 배포할 수 있습니다.

### 1단계: 새 구글 스프레드시트 생성
1. [Google 스프레드시트(sheets.new)](https://sheets.new)에 접속하여 새 스프레드시트를 생성합니다.
2. 시트 제목을 원하는 이름(예: `우리들의 마음 우체국`)으로 변경합니다.
   *(시트 탭이나 표는 미리 만들 필요가 없습니다. 앱이 실행될 때 자동으로 생성됩니다!)*

---

### 2단계: Apps Script 에디터 열기
1. 스프레드시트 상단 메뉴에서 **[확장 프로그램]** > **[Apps Script]**를 클릭합니다.

---

### 3단계: 코드 복사 및 붙여넣기

1. **`Code.gs` 코드 입력**:
   - 에디터 좌측의 `코드.gs` (또는 `Code.gs`)를 클릭합니다.
   - 기존 내용을 모두 지우고, 본 저장소의 [`Code.gs`](file:///Users/ohsooyeol/workspace/rolling-letters/Code.gs) 파일 내용을 복사하여 붙여넣습니다.
   - *(선택)* 상단의 `var ADMIN_MASTER_PIN = '0000';`을 원하는 4자리 관리자 비밀번호로 변경할 수 있습니다.
   - 저장(`Ctrl + S` / `Cmd + S`)을 누릅니다.

2. **`index.html` 파일 추가 및 코드 입력**:
   - 에디터 좌측 상단의 **파일 추가(+)** > **HTML**을 클릭합니다.
   - 파일 이름으로 `index`를 입력하고 Enter를 누릅니다 (`index.html` 파일 생성).
   - 본 저장소의 [`index.html`](file:///Users/ohsooyeol/workspace/rolling-letters/index.html) 파일 내용을 전체 복사하여 붙여넣고 저장합니다.

---

### 4단계: 웹 앱으로 배포하기

1. 에디터 우측 상단의 파란색 **[배포]** > **[새 배포]** 버튼을 클릭합니다.
2. 왼쪽 톱니바퀴 아이콘(유형 선택)에서 **[웹 앱]**을 선택합니다.
3. 배포 설정을 다음과 같이 지정합니다:
   - **설명**: `우리들의 마음 우체국 v1` (원하는 설명 입력)
   - **다음 사용자로 실행**: `나 (내 계정)`
   - **액세스 권한이 있는 사용자**: **`모든 사용자 (Anyone)`** *(중요! 학생/동료들이 로그인 없이 편지를 쓰려면 반드시 '모든 사용자'로 설정해야 합니다)*
4. **[배포]** 버튼을 클릭합니다.
5. **최초 1회 권한 승인 창**이 나타나면:
   - `액세스 승인` 클릭 → 본인 구글 계정 선택
   - *"Google에서 확인하지 않은 앱"* 경고 화면이 나오면 좌측 하단의 **[고급(Advanced)]** 클릭 → **`[프로젝트명](으)로 이동(안전하지 않음)`** 클릭 → **[허용(Allow)]** 클릭.
6. 배포가 완료되면 발급된 **웹 앱 URL**을 복사합니다.

---

### 5단계: 공유 및 사용 🎉
- 복사한 웹 앱 URL을 학생, 학부모, 동료 교사들에게 메신저나 알림장, QR코드로 공유하면 누구나 즉시 편지를 작성하고 감상할 수 있습니다!

## ❓ 자주 묻는 질문 (FAQ)

#### Q. 스프레드시트 탭이나 열 제목을 미리 만들어야 하나요?
> **아닙니다!** 사용자가 처음 접속하거나 편지를 쓸 때 `Letters` 시트 탭과 필요한 열(작성자, 관계, 내용, 색상, 비밀번호, 좋아요 수 등)이 자동으로 생성됩니다.

#### Q. 부적절한 편지가 올라왔을 때 어떻게 삭제하나요?
> 편지를 클릭하여 상세 보기 창에서 **[🗑️ 삭제]**를 누른 뒤, 선생님 전용 **관리자 마스터 PIN (`0000`)**을 입력하시면 즉시 삭제됩니다.

#### Q. 화면 상단에 *"이 애플리케이션은 Google Apps Script 사용자가 만들었습니다"* 배너가 떠요.
> 개인 일반 구글 계정(`@gmail.com`)으로 배포할 경우 구글 보안 정책상 상단에 안내 배너가 표시됩니다. **학교/교육청 Google Workspace 계정**(`@*.sen.es.kr`, `@*.cbe.go.kr` 등)으로 배포하시면 해당 배너 없이 깔끔하게 표시됩니다.

#### Q. 코드를 수정했는데 웹 앱에 반영이 안 돼요.
> 코드를 수정한 후에는 반드시 **[배포]** > **[배포 관리]** > 연필(수정) 아이콘 클릭 > 버전을 **[새 버전]**으로 선택 후 **[배포]**를 눌러주셔야 반영됩니다.
